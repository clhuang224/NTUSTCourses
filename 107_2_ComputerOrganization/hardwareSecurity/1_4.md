# 4: Intellectual Property Protection

## 什麼是IP
* 原創的想法
* 可能可以賺錢
* 中文常稱「智慧財產」
* IP reuse
    * IP Highway
* 法律保護

## VLSI Design IPs
有哪些電路設計相關的智慧財產？
### 設計的類型
* 演算法 Design altorithm
* 方法 Design methodology
* 微處理器 Microprocessor
* 記憶體 Memory
* 算術單元 Arithmetic Units
### IP的類型
#### Hard IP
* 例如：
    * GDSII file
    * custom physical layout
    * fully placed and routed netlist for specific technology library
* 彈性小，可預測
#### Soft IP
* 例如：
    * Synthesizable HDL source code
* 彈性很大，無法被預測
#### Firm IP
* 介於Hard和Soft之間，例如：
    * Placed RTL netlists(or sub-blocks)
    * Fully placed netlist for a generic library

## Why IP protection?
* 保護IP提供者，避免他們的IP被未授權使用
* 在製造跟運送過程中，保護所有類型的設計

## Hardware IP Piracy
* 逆向工程 Reverse engineering
> 可能被用逆向工程破解
* Chip overbuilding
> 可能被拿來修改
* Counterfeiting
> 被偽造
